Featured Agentic AI · Healthcare

YouRi — Agentic RAG Medical Assistant

An intelligent clinical question-answering assistant built on an Agentic RAG architecture with LangGraph, where every LLM response is grounded on verifiable sources to eliminate hallucinations.

  • Engineered a query router with three execution scopes (Internal / External / Hybrid) plus a triple-axis metadata filter, reaching 100 % scope accuracy vs 37 % for vanilla RAG on a 30-question clinical benchmark.
  • Built a PII pseudonymization pipeline that redacts patient identity (names → internal IDs, date of birth → age) before any external LLM inference, ensuring GDPR-aligned data handling.
  • Cut inference latency ×15 (38.7 s → 2.5 s) through INT8 quantization of the reranker while preserving relevance decisions on the real corpus.

Deep Learning · Medical Imaging

GlioScan — 3D Brain Tumor Segmentation

A U-Net pipeline that segments brain tumors from multi-modal MRI on the BraTS 2021 dataset, served through a FastAPI web interface.

  • Trained 2D and 3D U-Nets on FLAIR / T1 / T1ce / T2 volumes from 600 BraTS 2021 patients, reaching a mean Dice of 0.942 (whole tumor 0.926, tumor core 0.953, enhancing tumor 0.946).
  • Full PyTorch pipeline — volume caching, a combined Dice + cross-entropy loss, per-region metrics and test-time augmentation — trained in ~80 minutes on a single 6 GB RTX 4050.
  • Ships a FastAPI service with a /predict endpoint and an upload UI: drop a patient’s four NIfTI volumes and the tumor is overlaid on axial slices in seconds.

Data Engineering · Automation

Tayara.tn Vehicle Scraper

A dual-implementation scraper that extracts and structures vehicle listings from Tayara.tn — an automated n8n workflow for no-code scheduled runs, plus a standalone Python script for pipeline integration.

  • Multi-page scraping across 30+ pages with automatic retry and smart delays — roughly 20 pages in 2–3 minutes at a >95 % success rate.
  • Mistral AI agent cleans and normalises the key fields (make, model, year, price, fuel, transmission, location) into 100 % valid analysis-ready CSV.
  • Two interchangeable paths: an n8n workflow using the Jina.ai API for scheduled no-code runs, and a requests + BeautifulSoup script for developers who need custom filters or export formats.
